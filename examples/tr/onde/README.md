# examples/tr/onde/

onde テキストを対象として各モデルで翻訳・評価を行います。

- [gemma4](gemma4/)
- [gpt-oss](gpt-oss/)
- [qwen3.6](qwen3.6/)
- [qwen3.8](qwen3.8/)
- [muse-glimmer](muse-glimmer/)
- [ox-alpha](ox-alpha/)

onde はフランス語で「波」を意味します。ここでは物理用語として「波動」の意味で使用されています。

[TEMPLATE/](TEMPLATE/) はモデル追加用のひな形ディレクトリ（`make all` の対象外）。追加手順は [ADD_MODEL.md](../ADD_MODEL.md) を参照。
